## About Me

I am an **AI/ML & Software Engineer** specializing in developing high-performance machine learning models, computer vision applications, and interactive software systems. I bridge the gap between theoretical AI research and production-ready tools, building everything from custom terminal user interfaces to real-time physical simulations and local translation engines.

- 🧠 **AI & Machine Learning**: Building applications using LLMs (Llama 3, DeepSeek), offline translation models (NLLB-200), and computer vision tracking (OpenCV).
- ⚙️ **Systems & Simulation**: Developing high-performance physics simulations and graphics engines in C++.
- 🌐 **Web & Interactive UI**: Crafting bespoke web experiences and responsive user interfaces.
- 🛠️ **Developer Tooling**: Designing robust TUI/CLI utilities focused on performance, efficiency, and local privacy.
- 📍 Indore, India

## Featured Projects

Here are some highlights of projects I have designed and built:

*   **[FluxLumina](https://github.com/MdHussain121/FluxLumina)** - An interactive electrostatic sandbox and physics simulation for visualizing electric fields, potentials, and charge dynamics in real-time, built using C++.
*   **[OpenBabelFish](https://github.com/MdHussain121/OpenBabelFish)** - A high-performance, offline translation tool powered by Meta's NLLB-200. Features CPU/GPU acceleration, an interactive CLI, and automatic local model management.
*   **[Air Canvas CV](https://github.com/MdHussain121/Air_Canvas_CV)** - A computer vision project enabling users to draw on-screen in real-time using a webcam and hand gestures without hardware interfaces.
*   **[LinkCmd](https://github.com/MdHussain121/LinkCmd)** - A terminal application (TUI & CLI) for managing, drafting, and scheduling LinkedIn posts using NVIDIA NIM (Llama 3).
