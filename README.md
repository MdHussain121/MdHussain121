I build AI-powered software from the ground up — from custom language models and computer vision systems to browser extensions and physics simulations. My focus is on understanding systems deeply by building them under the hood, keeping things local-first, performant, and purposeful.

## Projects

| Project | Description | Stack |
|---|---|---|
| [**CooLM**](https://github.com/MdHussain121/CooLM) | ~42M parameter transformer built from scratch — custom tokenizer, training loop, ONNX export, browser inference. Trained in 22 min on a laptop GPU. | PyTorch · Python · ONNX |
| [**ContextFlow**](https://github.com/MdHussain121/ContextFlow) | Chrome extension that transfers conversation context between AI assistants (ChatGPT, Claude, Gemini) in under 10 seconds. | JavaScript · Chrome MV3 |
| [**ArchivAI**](https://github.com/MdHussain121/ArchivAI) | Local-first web archiver with AI auto-tagging, full-text search, and reader mode. No telemetry. Powered by NVIDIA NIM. | JavaScript · NVIDIA NIM |
| [**OpenBabelFish**](https://github.com/MdHussain121/OpenBabelFish) | Fully offline translation CLI powered by Meta's NLLB-200. CPU/GPU acceleration, zero cloud dependency. | Python · Hugging Face · NLLB-200 |
